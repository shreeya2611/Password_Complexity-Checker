# Password Complexity Checker

## Project Overview

The Password Complexity Checker is a Python application that evaluates password strength based on different security parameters such as length, uppercase letters, lowercase letters, numbers, and special characters.

## Technologies Used

- Python
- Tkinter
- Regular Expressions (Regex)

## Features

- Password strength analysis
- Weak password detection
- Strong password validation
- User-friendly interface
